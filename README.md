# نظام سیستم‌ها و روش‌ها | کارخانه چاپ لیبل

سامانه فارسی و راست‌چین برای استقرار نظام سیستم‌ها و روش‌ها در کارخانه چاپ لیبل؛ با تمرکز اولیه بر ثبت توقف ماشین‌آلات، پایش شاخص‌ها، مستندسازی روش‌های اجرایی و تنظیم‌پذیری بدون تغییر کد.

## وضعیت فعلی
این مخزن در مرحله آغاز پیاده‌سازی است. MVP به‌ترتیب شامل:
1. زیرساخت Docker Compose و PostgreSQL
2. API با Node.js و TypeScript
3. رابط کاربری React + TypeScript با پشتیبانی RTL
4. مدیریت ماشین‌آلات و ثبت توقف‌ها
5. فرم‌های پویا و قابل تنظیم از داخل برنامه
6. رویدادهای ممیزی و داشبورد پایه

## اصول طراحی
- تنظیم فرم‌ها، فیلدها، گزینه‌ها، قواعد و شاخص‌ها از طریق تنظیمات برنامه
- اعتبارسنجی سمت سرور؛ عدم اجرای JavaScript یا SQL دلخواه از تنظیمات کاربران
- ثبت رویدادهای ممیزی برای عملیات مهم
- نسخه‌بندی تنظیمات و انتشار کنترل‌شده
- اعتبارسنجی ورودی، کنترل دسترسی و استفاده از تراکنش‌های پایگاه داده
- رابط فارسی و راست‌چین

## اجرای محلی
پس از تکمیل فایل‌های برنامه، از فایل `.env.example` یک نسخه با نام `.env` بسازید و سپس اجرا کنید:

```bash
docker compose up --build
```
